# BKCleanHelper

macOS 原生菜单栏清洁工具。点击开始，准备 3 秒后临时屏蔽键盘、触摸板与外接键鼠，60 秒后自动恢复。使用 AppKit、系统字体、SF Symbols 和系统按钮，支持浅色与深色外观。

## 使用

1. 运行 `bash scripts/build.sh`，双击 `outputs/BKCleanHelper.app`。首次使用前建议将应用放到固定位置，再授权。
2. 在主窗口分别点击“前往设置…”，进入“系统设置 → 隐私与安全性”，允许“BKCleanHelper”的**辅助功能**和**输入监控**权限。
3. 如系统提示退出并重新打开应用，请照做。返回后，两项状态均显示“已允许”即可开始。
4. 点击“开始清洁”，松开所有按键和鼠标按钮。3 秒准备时间内可以取消；全屏显示“键盘与触摸板已暂停”后再擦拭。
5. 60 秒后自动恢复。需要提前恢复时，同时按住 **Control + Option + Command + U** 两秒。

“预览清洁界面”无需授权，显示 8 秒预览；**预览不屏蔽输入**。关闭主窗口会保留菜单栏入口；退出应用会终止清洁并恢复输入。

## 权限与限制

- 清洁期间，内置与外接键盘、鼠标、触摸板统一暂停。
- 电源／Touch ID 按钮、硬件强制关机无法屏蔽，请避开这些按钮。
- 应用拦截系统投递的输入事件，并不切断硬件供电。触摸板仍可能产生触感反馈。
- 多指系统手势、特殊功能键、第三方手势工具以及安全输入场景需要在目标 Mac 上实际验收；系统更新或其他输入工具可能影响覆盖范围。首次正式使用前，请先在空白文档中检查普通按键、系统快捷键、触摸板滚动及多指手势。
- 未完成实机验证时，不应将构建版本视为所有系统输入均已屏蔽的正式版本。
- 权限不足或无法创建 HID 位置的事件拦截时，拒绝启动，不会只显示一个假的清洁遮罩。系统中断拦截后结束本轮清洁。
- 此构建使用本机临时签名，没有 Apple 开发者公证。重新构建、替换或移动应用后，可能需要在系统设置中重新授权。不要为运行本工具关闭 SIP 或全局 Gatekeeper。

## 自动恢复

独立子进程拥有事件拦截和连续时钟截止时间，不依赖主窗口计时。主程序退出、通信断开、锁屏、睡眠或切换用户时解除。主程序另有后台看门狗，拦截进程失去心跳时结束它；进程终止后系统会移除其事件拦截。全屏遮罩不接收鼠标输入，避免界面异常成为另一个输入锁。

完全本地运行，无联网功能、不记录或回放输入内容、不修改系统键盘或触摸板配置、不安装驱动或常驻特权服务。

## 开发与验证

要求 macOS 13+、Xcode 命令行工具。当前构建针对本机 Apple 芯片；没有外部依赖。可用 Xcode 打开 `Package.swift` 阅读和调试源码；日常运行请使用构建的 `.app`，以便权限归属稳定。

```sh
bash scripts/check.sh
bash scripts/build.sh
```

模拟测试不会实际拦截键鼠。测试覆盖精确截止时间、连续按住提前解锁、重复停止、父进程断开、子进程暂停后恢复、断开的输出管道和无效命令。

实机验收：普通键、修饰键、⌘Tab、⌘Space、音量／亮度键；指针、点击、拖动、双指滚动、缩放、旋转、三／四指手势；外接键鼠；60 秒恢复；提前解锁；权限撤销；退出／异常退出；睡眠唤醒；多显示器。真实输入屏蔽需要用户手动授权，本项目的模拟测试不能替代该验收。
